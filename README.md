# PokéSpawn — Projeto Android

Aplicativo completo com login local, encontros de Pokémon a cada 15 segundos, captura, Pokédex e perfil.

## Abrir o projeto

No Android Studio, abra a pasta **PokeSpawn**, que contém `settings.gradle`. Consulte [as instruções completas](PokeSpawn/README.md).

## Downloads

- [APK de teste](downloads/PokeSpawn-debug.apk)
- [Projeto completo em ZIP](downloads/PokeSpawn-AndroidStudio.zip)

## Validação

Compilação, 11 testes automáticos e Android Lint aprovados. [Relatório de validação](PokeSpawn/validacao/VALIDACAO.md).

O projeto anterior continua disponível na pasta `PokeTeam_AndroidStudio`.
